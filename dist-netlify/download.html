Downloads

Choose your platform.

Every download is built from the current GitHub release. Start with the standalone Windows executable, or choose a universal macOS app or Linux x86_64 archive.

WIN

Windows

Windows 10 and later, x86_64. One executable with the Microsoft runtime and built-in profiles included. No installer, Rust toolchain, or companion files required.

Download for Windows

If Windows SmartScreen appears on first launch, click More info, then Run anyway. The executable is not code-signed yet, so Windows asks once per download.

MAC

macOS

Universal app for Apple Silicon and Intel Macs. Unzip the download and move DMXexpress to Applications.

Download for macOS

Requires macOS 11 or later. The app is not notarized yet: if macOS blocks the first launch, click Done, then open System Settings > Privacy & Security, scroll to Security, and click Open Anyway. On older macOS versions, right-click the app and choose Open instead.

LNX

Linux

x86_64 binary for a desktop with Wayland or X11 and ALSA audio. Extract the archive, make the binary executable if necessary, then run it.

Download for Linux

System graphics and audio drivers are still required.

Show files stay separate from the app.

On first launch, DMXexpress creates its show-data folder and seeds it with sample rigs, stage setups, the 2,200-model fixture library, and the gobo catalogue. Your work persists there, rather than being written beside the downloaded application.

Hardware is plug and play.

An Elgato Stream Deck is detected the moment it is plugged in — no Elgato software or plugins needed. Audio input works out of the box too: on Windows, DMXexpress can listen to the computer's own output and light whatever is playing.
