Getting Started

What DMXexpress is

DMXexpress is a native lighting controller with a built-in 3D visualizer. You patch fixtures, build looks, run effects, record cues, and stream the result to the real world over Art-Net. Everything happens in one window, and everything you build is visible on the virtual stage as you build it.

The one big idea

You build a look in the Programmer, then store it into something reusable — a Palette, a Preset, a Phaser, or a Cue. Playback runs underneath the Programmer, so whatever you are editing always wins until you clear it.

If you have read grandMA3 tutorials

DMXexpress is modelled on grandMA3 with friendlier names. Here is the translation:

DMXexpressgrandMA3What it is
ProgrammerProgrammerYour live scratch pad of values you are editing right now
GroupsGroupsSaved fixture selections
PalettesPresetsSaved values for one feature (color, position, and so on)
PresetsSnapshotsA whole-rig look, stored straight from the Programmer
PhasersPhasers / EffectsMoving, rolling effects built from channel components
StacksSequences / Cue listsAn ordered list of looks you step through
DecksExecutorsThe faders and Go buttons that play your stacks
ViewsViewsSaved window layouts

Suggested order of operations

Patch and Art-Net, then Groups, then Palettes (color and position first), then Phasers, then Stacks to record cues, then Decks to play, then Views to save your layout.

Getting Started

Install and run

Grab a prebuilt release for Windows, macOS, or Linux from the download page — no toolchain, installer, or companion files needed. An Art-Net node is only required for live output; the visualizer works with nothing else on the network.

Building from source instead

You need a current Rust toolchain and a GPU supported by wgpu.

Build and run
# run in development
cargo run

# optimized build
cargo build --release
./target/release/dmxpress

# run the tests
cargo test

First launch

  1. Launched outside a show directory, DMXexpress creates a per-user data folder and seeds it with the sample rigs and stage setups.
  2. Open Patch and add fixtures — search the built-in library, pick a built-in profile, or let a ShowBuddy patch load on macOS.
  3. Set Universe in the toolbar to your base universe. Slots 1–512 go there, slots 513–1024 to the next universe.
  4. Press ArtPoll to discover Art-Net devices, then pick a node in the Art-Net panel.
  5. Leave the Log window open while you learn — it narrates everything you do.

Network safety

DMXexpress transmits live lighting data. Confirm the selected interface, universe, patch, and Grand Master before connecting it to a real rig.

Getting Started

The Programmer, and why Clear matters

This is the single concept that trips up every newcomer, so it gets its own page.

What the Programmer is

  • It holds every channel you have touched since the last Clear.
  • It is an overlay that sits on top of all playback. While a channel is in the Programmer, you control it, not the cues.
  • Store copies the Programmer into a palette or cue. It does not clear it.
  • Only active channels get stored, which is what makes cue tracking work.

How to release it

  1. Press Clear in the Palettes window, or Clear prog in the Stacks window.
  2. Or type clear (or c) in the command line.
  3. Watch the n programmer ch active readout drop to zero.

Golden rule

After you record cues, clear the Programmer. If your faders and Go button appear to do nothing, it is almost always because the Programmer is still holding those channels.

Active-channel readouts

Both the Palettes window and the Stacks window show a live count of active Programmer channels. Use it as your safety light: a non-zero count means playback is being overridden somewhere.

Getting Started

Your first show

A complete run-through that produces a three-cue show. Assumes a few moving heads are patched. Do this once and the rest of the guide will make sense.

A. Save a selection

  1. Select all your movers in the Fixtures panel or on the stage.
  2. Open Groups, type Movers, press Store.

B. Build palettes

  1. With Movers selected, dial full blue in Channel control.
  2. Open Palettes, pick the Color tab, type Blue, press Store Color.
  3. Dial red, store it as Red.
  4. Point the movers at the crowd with Pan and Tilt, switch to the Position tab, store it as Audience.
  5. Point them center stage and store Center.

C. Record three cues

  1. Open Stacks, press New, name the stack Main.
  2. Recall the Movers group, click Blue, click Center, set Dimmer to full.
  3. Set Fade to 3 seconds and press Store cue. That is cue 1.
  4. Click Red, click Audience, press Store cue. That is cue 2.
  5. Open Phasers, add a PAN component, press Apply, return to Stacks and press Store cue. That is cue 3.

D. Play it

  1. Press Clear prog. This step is not optional.
  2. Open Decks, push the Main fader up.
  3. Press Go to step through cues 1, 2, and 3, each fading over its time.
  4. Pull GM down to dim the whole rig.

It is already saved

Groups, palettes, phasers, stacks, and views are written to disk automatically. Reopen DMXexpress and your show is still there.

Rig & Stage · Patch

Patch

Adds fixtures from the built-in fixture library or the hand-written DMXexpress profiles, on top of (or instead of) a ShowBuddy patch. This is where your rig is defined in DMX terms.

How to patch a fixture

  1. Open Patch from the toolbar.
  2. Search the Fixture library by name and maker — 2,200+ models — or pick one of the Built-in profiles from the dropdown. The line underneath reports the channel count and pan/tilt range of whatever is selected.
  3. Type a Name, set the Address (1–1024) and a Count (1–32).
  4. Press Add. Addresses advance automatically and multiples get numbered suffixes.

Managing what is in the rig

ControlWhat it does
Include ShowBuddy patchUntick to work with a DMXexpress-only rig. ShowBuddy preset banks are hidden too, and everything returns when you re-tick it.
DMXexpress fixturesFixtures you patched here. The cross button unpatches one.
ShowBuddy fixturesFixtures from the imported patch. The cross button removes one from the rig, but it stays restorable.
Removed / Restore allBrings excluded fixtures back into the rig.
Reload ShowBuddy patchTop toolbar button. Press it after editing the patch in ShowBuddy.

Address 513 and up

Slots 1–512 go to the base universe set in the toolbar. Slots 513–1024 go to the next universe up. A fixture that would run past slot 1024 is rejected and the reason is written to the Log.

There is a faster way in

The Inspector's Patch tab does the same job as a wizard: it finds a free address for you, names and numbers a whole batch, and places or hangs the lights as it patches them. The two share the same state, so they never disagree — use this window to audit and prune a rig, and the tab to build one.

Rig & Stage · Fixture library

The fixture library

DMXexpress ships with a built-in library of over 2,200 fixture models — 7,400+ patchable modes from 209 manufacturers — so most rigs patch without writing a single profile.

Where it comes from

The library is compiled from three open sources, merged so the best data wins:

SourceWhat it contributes
Open Fixture LibraryThe most precise channel data. It wins wherever sources overlap.
QLC+Models and alternate channel-count modes OFL doesn't carry.
GDTF ShareManufacturers' own data for the current professional ranges.

Every mode is flattened into its own entry with the channel list already in address order, and every channel's role is resolved from the source's own capability data rather than guessed from its name.

How to patch from it

  1. Open Patch from the toolbar.
  2. Type into Search under Fixture library — try chauvet spot — and optionally narrow the maker dropdown.
  3. Click a result. Each row is one channel mode of one model, with its details in the subtitle.
  4. Set Name, Address, and Count, then press Add, exactly as with a built-in profile.

Loaded only when needed

Uncompressed the library is about 14 MB of JSON, so it ships gzipped and nothing loads until the first search in the Patch window. After that it stays cached.

When a fixture is missing

Hand-written profiles cover anything the converters can't reach — the repository's FIXTURES.md documents the profile format, the channel helpers, and how to rebuild the library from the upstream sources with tools/build_library.py.

Rig & Stage · Fixtures panel

Fixtures panel

The left rail. One tile per patched fixture, filled with that fixture's live output color, so the panel doubles as an at-a-glance rig monitor.

Reading a tile

  • Top-left text is the fixture name, truncated to fit.
  • Bottom-left text is its DMX start address.
  • The fill is the fixture's current output color; text flips to black on bright fills.
  • A thick blue outline means selected.
  • Hovering shows the full name, the DMX range, and the channel count.

Selection modifiers

Six ways to draw a tile

The dropdown in the panel header changes the material the tiles are made of. Every look shows the same three things — the live colour, the name, the address — and answers the same selection outline; pick whichever one you can read fastest across a dark room.

LookWhat it is
LitA colour tile lit from above, matching the console's raised controls. The default.
Amp jewelA faceted pilot-light lens in a chrome bezel on a dark faceplate, glowing with the fixture's colour.
FutureA chamfered black slab with a glowing colour bar and corner brackets.
GlassA pane of tinted glass with a specular streak.

A tile's brightness tracks the fixture's real output, corrected so a dim lamp looks as dim as it actually is. The depth is painted with gradient meshes rather than textures, so a rig of two hundred tiles costs no more to draw than a flat grid.

Sizing the grid

Use the A- / A+ stepper in the panel header to shrink the tiles when you have a big rig, or enlarge them for touch use. The look you pick is saved to settings.json straight away.

Rig & Stage · Trusses & towers

Trusses and towers

Real mounting structures for the 3D stage: floor-stand towers, F34-style straight box-truss runs, and curved radius truss — all with snap-on light slots, so the virtual rig hangs the way the real one will.

The three structures

StructureWhat it is
TowerA floor stand with one crossbar and eight light slots — four top, four bottom.
F34 trussA straight box-truss run with mount slots spaced every half metre along each of its four faces.
Radius trussA curved segment sweeping an arc, with two faces. Set the radius and arc angle and the slots follow the curve, aimed along the tangent.

Five more shapes are built out of those three in one press — goalpost, box, ring, tower pair, and arch — and stay grouped afterwards, so you move and turn the whole thing as one object. See the Build tab.

How to rig one

  1. Open the Inspector's Build tab (Alt-4) and click one of the eight element pads. Keys 1 to 8 do the same while the pointer is over the tab.
  2. Size it in the parameter card underneath — or right-click the pad for the standard lengths, radii, arcs, and heights.
  3. Drag lights near the blue rings to snap them onto slots; drag them away to detach. To hang a whole selection at once, use Hang on on the Selection tab.
  4. Click the structure with no lights selected and the Selection tab becomes its editor.
  5. Edit X, Z, and Height numerically. Straight truss gets Length and Heading; radius truss gets Radius, Arc, and Start angle.
  6. Pitch tilts the whole run out of the horizontal plane, and Roll sets which way a pitched truss faces.
  7. Delete one from the Build tab's outliner, or press Backspace with the pointer over that list. It asks first and tells you how many lights it will unhang.

Mounted lights travel with the structure

Move or rotate a truss and every snapped light swings with it, keeping its slot. Editing a light's own X, Y, or Z detaches it; rotating the light does not. The Selection tab's Re-seat button puts a detached light back on its nearest free slot.

Setups remember structures

The Build tab's Setups section saves and reloads the whole physical arrangement — light positions, copies, towers, and truss — so a rig you build once can move between shows. Save it as Rig only to keep the structures as a template with no light positions in it.

Rig & Stage · Configs

Configs and setups

Two different scopes of save. A configuration is the whole show. A setup is just the physical arrangement.

What a configuration contains

Stage settings, the 3D layout (placements, duplicates, towers, truss), patched fixtures, whether the ShowBuddy patch is included, excluded fixtures, groups, palettes, phasers, presets and preset folders, stacks, views, the universe, the grand master, and the cue fade time. Files land in configs/ as readable JSON.

What it deliberately leaves out is your workspace: which Inspector tab is open, how wide the panel is, which sections are folded, and what the stage draws. Those belong to the machine rather than the show, and live in inspector.json instead — so loading somebody else's configuration never rearranges your desk.

How to save and load a show

  1. Open Configs from the toolbar.
  2. Type a configuration name and press Save.
  3. Press Load on any row to swap the entire show over.
  4. Press the trash button and confirm to delete one.

Starting fresh

  1. Press New show.
  2. Tick Remove ShowBuddy lights and presets to keep only DMXexpress fixtures.
  3. Tick Reset light positions to defaults if you want a clean stage.
  4. Press Start fresh. Stage settings and DMXexpress-patched fixtures are kept.

Setups are lighter

Setups live in the Setups section of the Inspector's Build tab, not here. They store the physical arrangement only — light positions, copies, towers, and truss — so you can reuse a rig across different shows, and load the structures without disturbing the lights.

The right-hand panel, and the part of the app you touch most. It is five tabs — Presets, Selection, Stage, Build, Patch — sharing one strip, one context line, and one scroll area. Store looks, move lights, aim the camera, rig truss, patch fixtures: all of it without opening a window.

The context line

Under the tab strip a single row always says what is picked, on every tab. It carries the live output colour of the first selected light as a swatch, a title, and a detail line: 6 lights · SlimPAR ×6 · 4 hung for a selection, DMX 17–25 · 9 ch for one light, F34 truss 2 · 4 / 24 slots · 6.0 m for a truss, 8.0 × 6.0 m · 0.3 m high for the stage box. With nothing selected it tells you what to do next.

  • Click the row to jump to Selection — or to Patch when nothing is patched yet.
  • Press the × to drop the selection.
  • Right-click for Select every light, Select same type, and Clear selection.
  • Hover the colour swatch for the first light's live RGB values and its output level.
  • FROZEN and BLACKOUT pills appear on the right when either is in force.

Follow selection

In that same right-click menu is Follow selection. Turn it on and the Inspector jumps to the Selection tab every time you pick something new on stage — worth having while you lay a rig out, worth turning off while you programme.

Your workspace is not show data

Which tab is open, how wide the panel is, which sections are folded, and what the stage draws live in inspector.json and are deliberately kept out of saved configurations. Loading somebody else's show never rearranges your desk.

Inspector · Presets tab

Presets tab

Store what the Programmer is holding as a look, then get it back with one press. A preset carries a stable id, so every reference to it — a board pad, a deck key, an audio trigger, the chase source — survives a rename, a reorder, or a delete.

Storing a look

  1. Build something in the Programmer: a group, some palettes, a dimmer, a running phaser.
  2. Type a name into the store card and press Store look. The button is gated while the Programmer is empty, and says so.
  3. Pick a folder in the store card first and the look is filed straight into it.
  4. Recall a preset, change it, then press Update with current look to overwrite the lit one.

Pads read their own colour

Every pad is coloured from the values inside it — the mixed emitter colour for a colour look, amber for a dimmer-only one, deep blue for a position, plain raised grey for anything else — unless you pick a colour by hand. Badges mark the presets carrying oscillators, phasers, or a colour cycle. The same colour reaches the Presets board and the Stream Deck, so a look is the same shade everywhere you meet it.

The recall row

ModeWhat a plain click does
CutArrives instantly, whatever the Transition window says.
FadeArrives over the seconds set beside it, 0.1 to 20.
As setUses the Transition window's duration. The pill warns you when that duration is zero.

A preset given a recall time of its own wins over the row, and shift-clicking any pad always cuts. Recall onto selection applies only the channels belonging to the lights you have selected, which is how you drop one look onto half a rig.

Organising the pool

  • Search the pool, switch between Grid pads and List rows, and set the pad size to small, medium, or large.
  • Sort Manual, Alpha, or Newest.
  • Drag pads onto a folder to file them, or onto each other to reorder.
  • Pin the handful you reach for constantly — they get their own strip above the pool.
  • A Recent strip keeps the last few you recalled.
  • Right-click a pad for Duplicate, Move to, Set as chase source, To board, Edit pad, and Delete.

The Presets board

The board button opens a 4 × 9 page of pads laid out exactly like the Stream Deck's Presets page — the same slots, the same reserved corners for select-all, Clear, and Tap. What you arrange here is what is under your fingers on the device, and a show with no deck plugged in gets the same board on screen.

  1. Turn Arrange on.
  2. Click a pad to point it at a preset, or at a ShowBuddy bank preset.
  3. Drag pads to swap them; right-click to clear one.
  4. Give each pad its own colour, four-letter label, and artwork.
  5. Press Fill to lay a whole folder out in one go.

Pads hold preset ids, so renaming or reordering the pool never re-points a pad at the wrong look. A pad whose preset has gone shows a muted ? and says so when you press it.

ShowBuddy banks

If your ShowBuddy show carries preset banks they appear in their own section, one bank open at a time. Clicking a preset inside applies it to the whole rig; you can also Import as native preset, or import a whole bank into a folder, and edit it from then on like anything else you stored. The section is hidden while the ShowBuddy patch is switched off in Patch.

The output row

ButtonWhat it does
BlackoutEvery channel to zero, every effect stopped. The Programmer keeps nothing. This is the panic button.
ClearA staged clear: encoders first, then effects, then blackout — one stage per press.
ReleaseDrops the lit-preset highlight without changing a single output value.

Underneath, one line always names the preset currently lit, or reads No preset active.

Inspector · Selection tab

Selection tab

Everything that moves, turns, lines up, aims, or hangs whatever is picked on the stage. A summary card, a Select bar, the transform grid and nudge pad, then a five-page tool strip. Pick a tower or a truss instead of lights and the tab shows that element's editor on its own.

The summary card

The top card counts what is selected and breaks it down — how many moving heads, how many are hung on the rig, how much space the selection covers as width × height × depth. With a single light picked it names it and gives its DMX range.

Select

An always-visible bar of verbs that build a selection without going near the stage: every light, every light of the same type as the last one picked, every copy of it, every mover, every par, every bar, everything not selected, everything not hung on anything, everything hung on the picked element, or the element a light hangs from. Your stored groups sit here too. Shift-clicking any of them adds to the selection instead of replacing it.

The transform grid

X, Y (height) and Z in metres, then Spin for a moving head's base, or Yaw, Pitch, and Roll for a fixed body, plus Size and a housing Opacity slider for the visualizer. Where the selected lights disagree, the row reads mixed rather than lying about a value; typing into it sets them all. Each row has its own reset.

Editing X, Y, or Z detaches a light from the tower or truss it hangs on. Rotating does not. Re-seat puts a detached light back onto its nearest free slot.

Nudge

A pad of six arrows that shift the selection by a fixed step. Shift multiplies the step by ten, Alt divides it by ten, and the arrow keys over the stage do the same thing. Switch the axes to camera-relative and "left" means left from where you are sitting rather than stage left — much easier once the camera is off-axis.

The five tool pages

PageWhat is on it
MoveAlign and distribute on any axis, mirror across X or Z, flip 180, rotate by a step, set a common height, snap to a grid, spread or pull the selection in by 10 %, scatter, stagger, cross, centre on stage.
ArrangeRe-lay the selection into a line, an arc, a circle, or a grid, with ready-made spacings, radii, sweeps, and column counts one tap away. A line can be fitted to a total length instead of a fixed spacing.
AimPoint every selected light straight down, straight up, out level, at the stage centre, at the selection's own centre, at a typed point, or at the chase and transition spheres on stage. Fan opens them across an angle. Moving heads are aimed with pan and tilt; pars and bars are turned bodily.
HangHang the selection onto a tower or truss: pick the element, pick the face, and choose whether the lights fill from start, sit centred, or spread across the free slots. Detach and Unhang take them off again.
ClipCopy one set of lights' placement — position, rotation, size, opacity, independently — and paste any part of it onto another set. Match anchor gives every selected light the rotation and size of the last one picked.

Copies

Duplicate makes copies of the selected lights, with a step across and upstage per copy. Copies share the fixture's DMX address, so they cost nothing on the wire — they are extra bodies on stage, useful for a row of pars driven from one patch entry. Remove copy deletes them; the last copy of each fixture always stays.

Nothing changes while you look at it

Every button here queues one action and applies it after the panel has finished drawing, then writes one plain sentence into the Log — Arranged 12 lights in a circle. Cmd-Z over the stage takes it back.

Inspector · Stage tab

Stage tab

How you look at the rig. Camera mode, quick views, saved camera bookmarks, what the stage draws, and the size of the stage box. Nothing here is undoable, because none of it is show data — the camera has its own escape hatch instead.

Camera

  • Switch between Orbit and Fly. Orbit: right-drag orbits, middle-drag pans, the wheel zooms. Fly: WASD moves, Space goes up, Shift down, the arrow keys look around.
  • Seven quick-view pads jump to a stored angle: Iso, Front, Back, Left, Right, Top, and a front-of-house seat. Shift-click one to keep your current zoom instead of re-framing.
  • Frame fits the selection in view (F over the stage), Fit rig fits the whole rig and the stage box (Home).
  • Orbit and tilt buttons step the camera 15° round and 10° up or down; zoom buttons scale the distance.
  • Camera → previous puts you back where you were before the last jump.
  • Open Stage controls for the exact numbers: yaw, pitch, distance, field of view, and the target X, Y, Z the camera is aimed at.

Saved cameras

  1. Frame a view you like.
  2. Type a name and press Save. Leave the name blank and it is numbered for you.
  3. Give the bookmark a digit from 1 to 9, then press that digit over the stage to fly back to it.
  4. Tint a row so it stands out, reorder with the up and down buttons, rename in place with F2, or Update to current camera to re-point it.

Tour walks the saved cameras one after another on a timer you set — eight seconds each by default — which is the easy way to show a rig off, or to check a look from every seat in the house. You need at least two saved cameras.

Show

The fast way in. One press patches a batch, places it, and selects it, so a rig goes up in one pass instead of a light at a time. The tab reads top to bottom: pick a model, check the preview, set count, address and name, choose where it lands, press Patch.

Programming · Groups

Groups

A group is a saved fixture selection — no values. Build the ones you keep coming back to and everything downstream gets faster.

How to build and use groups

  1. Select fixtures on stage or in the Fixtures panel.
  2. Type a name and press Store. The button is disabled with an empty selection.
  3. Click a tile to recall it, replacing the current selection.
  4. Shift-click several tiles to combine groups into one selection. The click order is remembered as a chain, shown as #1, #2 on the tiles — that chain is what the Orders window turns into a route.
  5. Right-click a tile for Recall, Add to selection, Update from selection, and Delete.

Effect phase mode

The right-click menu also offers Individual fixtures or One fixture. In One fixture mode the entire group takes a single phase slot in phaser spreads, so a cluster of pars behaves as one unit inside a chase instead of fanning internally. It also collapses to a single point in space, so spatial chases sweep past the whole cluster at once. Tiles show a 1 light marker when this mode is on.

Because a folded group has to move as one, the stage will not let you select part of it — clicking any member pulls in the rest.

Editing several groups at once

Shift-click a run of groups, then right-click any of them. Below the per-group controls you get a Chained groups section with All: individual fixtures and All: one light each, so a whole route can be folded or freed in one action.

An active order overrules the mode shown here

If the running order folds lights into a multi-light step, those lights move as one no matter what their group says. The pool tells you so: an ORDER banner appears at the top, affected tiles read · order, and the right-click menu offers Release from order to split the step back apart.

Groups worth having

All Movers, Front Wash, Back Truss, Odd, Even, and one group per tower. Ten minutes of setup here saves the whole night.

Programming · Orders

Orders

An order is the path an effect travels. Without one, every spread fans out in fixture number order, which is rarely the shape you actually want on stage.

What an order is made of

An order is a list of steps. Each step holds one light, or several lights that share a phase and move together as a single super-fixture. A phaser hands out one phase slot per step, in order, so the steps decide both the sequence and what counts as one light.

How to build one from groups

  1. In Groups, click the first group, then shift-click the rest in the order you want the effect to travel. Tiles number themselves as you go.
  2. Open Orders. The chain appears at the top as numbered pills.
  3. Type a name, then choose how the chain becomes steps:
  4. Store lights — one step per light, still sequenced group by group. A light already placed by an earlier group is not repeated.
  5. Store groups as fixtures — one step per group, so each group takes a single phase slot and moves as one light.

Store selection in patch order ignores the chain and uses the raw stage selection instead.

Running and editing

  • Click an order tile to make it the active route; click Patch order to go back to fixture numbering.
  • The tile shows how many steps it has and how many of those are multi-light units.
  • Right-click for Edit, Select its fixtures, Reverse, and Delete.
  • In the editor, each step can move up or down, merge into the step above it (folding two slots into one), split back into one step per light, or be removed.

Overlapping groups

A light can belong to several groups, which used to make its phase ambiguous. The active order settles it: order steps claim their lights first, in sequence, then any One fixture group still wholly unclaimed collapses into a unit, and whatever is left keeps patch order with one slot each.

Folded steps cannot be picked apart on stage

While an order with multi-light steps is active, clicking one of those lights selects the whole step — and the Groups window may still describe them as individual fixtures. The Orders window warns you when this is happening and offers Split every folded step to undo it in one press.

Where orders show up

Phaser spreads, palette cycle spacing, and the spatial position an effect reads for each unit. The Phasers window prints the live unit count and which route it is following, so you can see the shape before you commit to it.

Presets

How to store and organize presets

The Presets board

A 4 × 9 page of pads, laid out exactly like the Stream Deck's Presets page — the same slots, the same reserved corners for select-all, Clear, and Tap. Effects & Motion · Audio in

Audio in

Pick any audio source the computer can hear, watch its spectrum, let the beat tracker press TAP for you, and draw trigger bands on the graph — when the bass crosses this line, throw this palette at that group.

Picking a source

  • On Windows, every output device is offered as a System audio loopback source — play a track and light it, no cabling.
  • Microphones and other inputs work on every platform.
  • On macOS and Linux, capturing system audio needs a virtual device such as BlackHole or a monitor source.

Following the beat

The analyser folds a live FFT into 64 log-spaced bands and feeds spectral flux into a predict-and-correct beat tracker. Each detected beat becomes a tap on the existing beat machinery — the tracker is a very patient drummer pressing the TAP button — and a confidence readout says how periodic the music actually is. Everything that follows the master beat follows the band.

Band triggers

  1. Draw a band on the spectrum graph, or start from a named range: Sub, Bass, Low-mid, Mid, High-mid, Presence, Air.
  2. Set the threshold line. The trigger fires when the band's energy crosses it.
  3. Pick what it paints: a palette or a native preset, aimed at a group or the whole rig.
  4. Choose how it fires: Gate holds while the band is above the line with attack and release shaping, One-shot fires on each crossing then decays, and Follow tracks how far above the line the band sits.
  5. Pick a merge mode — Override, Highest, or Add — the same choices scenes use.

Level-independent by design

The spectrum is normalised against a slowly decaying reference peak, so the graph and your triggers behave the same at rehearsal volume and show volume. Audio settings stay machine-local on purpose — device names differ per computer.

Effects & Motion · Beat

Beat

The master clock. Turn it on, tap along with the band, and every card that opts in — phasers, palette sequences, oscillators on musical rates — locks to the song.

How to sync to a band

  1. Open Beat and tick Master BPM.
  2. Tap the big TAP button, or press the space bar, on the beat — or open Audio in and let the beat tracker tap for you.
  3. Watch the four-circle bar indicator. The orange circle is beat one.
  4. Use x2 or ÷2 if the detected tempo lands on the wrong subdivision.
  5. Pause for more than two and a half seconds, then tap again to reset the downbeat.

How tapping is interpreted

  • Taps more than 2.5 seconds apart start a fresh run.
  • Up to nine taps shape the tempo, which is clamped between 30 and 300 BPM.
  • The first tap of a run marks the bar downbeat; later taps nudge to the nearest beat.
  • Drift is applied to the live look, any running transition, the chase, and the palette cycle when it is following the master beat.

The time machine

Below the tap controls is a set of transport tools that bend the flow of animation time itself. Everything on a clock — phasers, oscillators, chases, palette cycles — follows, and status pills across the top always say what is currently in force.

ControlWhat it does
Reverse / ForwardRuns every effect backwards or forwards. Sweeps retrace their path, chases travel the other way down the rig.

Space bar works anywhere

As long as the Beat window is open, free-fly mode is off, and no text field has focus, the space bar taps. You never have to aim at the button mid-song.

Playback · Stacks

Stacks

A stack is a cue list: an ordered set of looks you step through with Go. This is theatre-style playback, and it is where tracking lives.

How to build a stack

  1. Press New and rename the stack in the text field.
  2. Build a look in the Programmer: a group, some palettes, a dimmer, maybe a phaser.
  3. Set Fade in seconds.
  4. Press Store cue. The button is disabled while the Programmer is empty.
  5. Change the look and press Store cue again for cue 2, and so on.

Tracking

A cue records only the channels you touched. Channels you did not touch track through from earlier cues, exactly like a real console. That keeps cues small and makes edits painless: change a color in cue 2 and every later cue that never sets a color follows.

The record mask

The Record row has one toggle per feature: Dimmer, Position, Color, Beam, Focus, and Control. Turn off Position to store a color-only cue. All toggles on records everything.

Playing a stack

ControlWhat it does
GoFades to the next cue, wrapping at the end of the list.
Row play buttonJumps straight to that cue.
Cue gridNumber, editable name, per-cue fade time, jump, and delete. The current cue's number is bold green.
Clear progEmpties the Programmer so the stack's output actually shows through.
Delete listRemoves the whole stack.

Palette references survive

Channels linked to a palette are stored as references rather than raw numbers, and resolve when the cue fires. Edit the palette, re-fire the cue, and the cue updates.

Playback · Decks

Decks

The executor bar across the bottom of the screen. This is your hands-on surface for running the show live.

Grand Master

One vertical fader on the left, labelled GM, scaling every dimmer in the rig with a percentage readout underneath. Pull it down for a quick fade to black.

Stack strips

  1. Each strip shows the stack name, turning green while it plays.
  2. Below it, the current cue name, or a dash when the stack is off.
  3. Ride the vertical Master level fader to fade that whole cue list in and out.
  4. Press Go to fire or advance cues.
  5. Press Off to release the stack so it stops outputting. It is disabled unless the stack is playing.

Grand Master only scales dimmers

Fixtures with no dimmer channel — raw RGB pars, for instance — will not dim from GM. Use a dimmer palette or the channel sliders for those.

Prefer physical keys?

Plug in an Elgato Stream Deck and busk presets, palettes, phasers, and chases from real keys — see Stream Deck.

Playback · Stream Deck

Stream Deck

Plug in any Elgato Stream Deck over USB and DMXexpress takes it over as a control surface — no Elgato software or plugins involved. Every key is drawn live by the app with its own color, label, and artwork. Whichever deck answers first is used, and if it is unplugged mid-show it reconnects by itself.

Turning it on

  1. Open Palettes and check Send to Deck — it is on by default, and the detected model is named beside it.
  2. If another program is holding the deck, close it so DMXexpress can reach the device.
  3. Turn the Mode knob to cycle through the four pages.

  1. Open Phasers and find the deck section: one tile per key, in pages of 36.

Playback · Views

Views

Named snapshots of your workspace. A view captures both the open windows and the stage camera position, so you can flip between a programming desk and a playback desk instantly.

How to save a view

  1. Arrange the windows you want open and park the stage camera where you like it.
  2. Type a name next to Name.
  3. Press Save.
  4. Click the view's button later to restore both the layout and the camera.
  5. Press the trash button to delete a view.

What a view captures

The camera snapshot and fly-mode state, plus the visibility of Art-Net, Transition, Chases, Groups, Orders, Scenes, Audio, Palettes, Phasers, Stacks, Decks, Command, Log, and Oscillator. Beat, Gobos, Patch, Configs, DMX monitor, Settings, and the Views window itself are not part of a view, so utility windows stay where you left them.

Two views to start with

A Program view with Palettes, Phasers, and Stacks open, and a Playback view with Decks, Stacks, and the command line.

Output & Fixes · Art-Net

Art-Net output

DMXexpress streams two contiguous DMX universes over Art-Net at roughly 40 frames per second. The Art-Net panel docks to the top of the window and is where you choose the destination.

How to get output running

  1. Set Universe in the top toolbar. Slots 1–512 go there, 513–1024 to the next universe.
  2. Press ArtPoll to broadcast a discovery packet.
  3. Click a discovered node row to unicast to it. Each row shows the IP address, the short name, and the long name underneath.
  4. Click Broadcast 255.255.255.255 to go back to broadcasting to everything.
  5. For a node that does not answer ArtPoll, type its address into Manual target IP and press Use.

A valid manual address is confirmed in the Log; an invalid one reports Invalid IP address. While no nodes have answered, the panel simply reads Searching.

Before you connect to a real rig

Confirm the interface, the universe, the patch, and the Grand Master position. Do not rely on DMXexpress as the sole safety mechanism for a live production.

When this panel is not enough

The Network screen is the full version: it picks the network interface, switches between Art-Net and sACN (or runs both), lists every node and source it hears, and has a checklist that tells you in sentences why nothing is arriving. Open it from Settings → Network….

Output & Fixes · Network

The Network screen

Everything needed to get lighting data out of the console and into a node — and to see why it is not arriving. Protocol setup, live diagnostics, a troubleshooting checklist, test patterns, and a packet monitor, in four tabs. Open it from Settings → Network….

The status strip

It sits above the tabs and stays there whichever one you are on, because those are the four numbers that matter: is it sending, how fast, to where, and any errors. Frames actually sent in the last second should read about 40. Enabled, but no frame has left in the last second and Nothing is being sent are the two readings worth acting on.

Setup

  • Choose the protocol: Art-Net, sACN (E1.31), or both at once.
  • Pick the network interface to send from, or leave it on any interface.
  • Choose how Art-Net packets are addressed — automatic (unicast to the picked node, else broadcast), limited broadcast, or multicast.
  • Set the base universe. The screen spells out the Art-Net Port-Address it maps to, Net switch and Sub-Net switch included, so you can match a node's front panel without arithmetic.

Settings are saved to network.json and pushed to the output thread as one change.

Nodes & sources

Every Art-Net node and sACN source heard on the wire, with its IP address, names, firmware, and which universes its ports are set to. A node that has not answered for five minutes drops off the list; a silent sACN source drops after thirty seconds. The table flags the common mismatch out loud: none of this node's output ports is set to a universe we send.

Checklist

Live checks that say what is wrong and what to do about it, one finding per row, each marked OK, warning, or fail. It is the first place to look when a rig is dark and you do not yet know why — it reads the same state the other tabs show, and turns it into sentences. Copy diagnostics puts the whole report on the clipboard for a bug report or a message to whoever runs the network.

Test & monitor

  1. Run Full on — every channel at 255 — to answer the first question: does anything light at all?
  2. Or run a chase pattern to walk the universe channel by channel and find a mis-addressed fixture.
  3. Set how long the pattern holds before the show comes back, or end it at once.
  4. Watch the packet monitor underneath: the last fifty packets with their direction, kind, and destination. Freeze the list to read it while packets keep flowing underneath.

A test pattern is real output

Full on drives the actual rig. Confirm the universe and the interface first, and be sure nobody is standing in a beam.

Output & Fixes · DMX monitor

DMX monitor

A live view of all 1024 output channels, plus a per-channel override so you can test wiring end to end without touching your show.

Reading the list

  • Each row is one DMX slot: address, a level bar, the numeric value, an override checkbox, and the owning fixture's name.
  • The level bar is green normally and orange while that channel is overridden.
  • The header reports either No overrides active or a warning with the override count.

How to test a fixture

  1. Open DMX from the toolbar.
  2. Scroll to the address you want. The fixture name on the right helps you orient.
  3. Tick its checkbox. The channel is forced to 255 on the wire, on top of everything else.
  4. Drag the override value to test a specific level.
  5. Press Clear all to drop every override when you are done.

Overrides outrank everything

An override sits above cues, phasers, holds, and the Grand Master. Always clear them before you run a show.

Output & Fixes · Freeze & blackout

Freeze and blackout

Three different ways to stop, each with a different scope. Knowing which one to reach for is the difference between a clean save and a dead stage.

Freeze

The FREEZE button in the top toolbar holds the exact current output and pauses every oscillator, transition, chase, palette cycle, cue fade, and timed ramp. UNFREEZE resumes every one of them at the same phase, because the paused duration is added to each clock rather than reset. Use it to hold a look while you go fix something.

Blackout

The Blackout button at the bottom of the Inspector's Presets tab writes a black frame and releases the active preset, all running phasers, holds, the transition, and the chase. This is the full stop. A BLACKOUT pill appears in the Inspector's context line while it is in force, so you always know.

Clear, beside it, is the gentler version: one press drops the encoders, a second drops the effects, a third blacks out. Reach for it when you want the stage back a layer at a time rather than all at once.

Command line blackout

Typing black or bo releases every stack and clears the Programmer. Playback stops, but stage effects owned by the Inspector are untouched.

Grand Master

Pulling GM to zero scales every dimmer to nothing but leaves everything running underneath, so pushing it back up restores the show exactly. Note that fixtures with no dimmer channel, and phaser hold or lock tiles, ignore it.

Output & Fixes · Log

Log

A small floating window that narrates everything the app does. It is display-only by design: no filters, no severity levels, no clear button.

What lands in it

  • How many fixtures loaded from the patch, and any patch warnings.
  • Store and recall confirmations for groups, palettes, presets, and cues.
  • Command line feedback, including usage errors and unknown commands.
  • Art-Net target changes and invalid IP addresses.
  • View changes.

How to use it

  1. Click Log in the top toolbar.
  2. Scroll back through the history; the view auto-follows new entries.
  3. Use A- / A+ to change its text size.

Keep it open while learning

Every action you take is described in one line. It is the fastest way to understand what a button actually did.

Output & Fixes · Plugins

Plugins

A plugin is one script file that extends the console: it can paint its own effect layer under the programmer, open a window of its own controls, or re-tint the whole theme. Scripts are sandboxed — no file, network, or system access, and runaway loops are stopped with an error instead of a hang.

Installing one

  1. Download a .rhai file — the plugin marketplace lists reviewed ones.
  2. Open Plugins from the toolbar and drag the file onto the window. Or press Open folder, copy it in, and press Reload all.
  3. Tick the plugin to enable it. Untick to stop it instantly.

The window, row by row

ControlWhat it does
CheckboxEnables the plugin: its layer starts mixing, its theme applies, its window becomes available.
WindowShows the plugin's own control window, when the script declares sliders and buttons.
ReloadRecompiles that script from disk — edit, save, reload, hear the difference.
RemoveDeletes the script file, after a confirmation.
Get pluginsOpens the marketplace in your browser.

How plugin layers sit in the mix

Plugin layers render with the scenes, underneath the programmer — so whatever a script paints, your own programming always wins on the channels you are holding. Each script picks how it folds in: mix takes its channels over, highest keeps whichever is brighter, add sums on top.

Errors

A script that fails shows its error in red in the Plugins window, and the failing hook is parked so it cannot spam. Fix the file and press Reload. print("...") output lands in the Log window.

Write your own

The developer section of the marketplace documents the whole format — it is one file with four optional functions, and the three bundled plugins double as worked examples.

Output & Fixes · Troubleshooting

Troubleshooting

The problems people actually hit, and the one-line fix for each.

My playback does nothing

The Programmer is still holding those channels. Press Clear prog or type clear. Check the active-channel count reads zero.

My palette edit did not change the cue

Palette references resolve when a cue fires. Re-fire the cue with Go or its row play button.

A cue is missing something I set

Store only records channels you actually touched, filtered by the Record mask. Confirm you moved that channel and that its feature toggle was on.

Some fixtures will not dim from the Grand Master

GM scales dimmer channels only. Raw RGB fixtures have no dimmer, so use a dimmer palette or drive the color channels down instead.

A fixture is stuck on and ignores everything

Check for a phaser hold or lock tile still running, and check the DMX monitor for a leftover channel override. Both outrank normal output.

Nothing reaches my node

Open the Network screen and read the Checklist tab — it names the fault and the fix in a sentence. Failing that: confirm the universe in the toolbar, press ArtPoll and select the node, or set a manual target IP. Verify the fixture's address falls inside slots 1–1024, and read the Log for the last target change.

Packets are going out but the rig is dark

The node is probably listening on a different universe. The Network screen's Nodes & sources tab says so outright when a node's output ports do not match anything you send. Run Full on from the Test & monitor tab to settle whether the problem is on the wire or in your patch.

I cannot find the Setups button any more

It moved. Setups now live in the Inspector's Build tab, under the outliner, along with Clear rig and Reset lights.

Everything is moving but nothing responds to edits

Check whether FREEZE is engaged in the toolbar. The button reads UNFREEZE and turns blue while output is held.

A fixture I patched vanished

Open Patch. It may be in the Removed list, or Include ShowBuddy patch may be unticked. Press Restore all to bring excluded fixtures back.
